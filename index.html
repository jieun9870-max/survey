안녕하세요, 서울대학교 환경설계학과에서 BIM 기반 조경설계 자동화를 연구하고 있는 석사과정생 이지은입니다. 현재는 조경 인허가 실무의 디지털 전환을 연구하고 있습니다. 본 연구는 학위 논문으로 마무리되며, 현장 실무자분들의 솔직한 의견이 가장 중요한 연구 자료입니다.

보유 자격

건축기사 토목기사 조경기사 도시계획기사 BIM 건축전문가 ADsP 빅데이터분석기사

→ 설계 도면을 읽고, 인허가 실무를 이해하며, 데이터로 분석할 수 있는 융합 연구자입니다.

본 연구에 대하여

BIM 기반 생태면적률 자동 산출 및 최적화 의사결정 지원 시스템 개발
: 서울시 기준을 중심으로

⏱️

산출 시간

Revit 위에서 작동하는 pyRevit 플러그인으로 생태면적률을 3분 안에 산출

🤖

AI 자동화

AI(OpenAI API)가 수목·재료를 자동 매핑하고, 가중 그리디 알고리즘이 예산·공간 제약 안에서 최적 대안을 제시

✅

검증 완료

수작업 대비 정확도 ±0.1%p, 작업 시간 30분~1시간 → 3분으로 검증 완료

"본 연구는 도시설계학회 학술대회에서 우수 연구로 선정된 바 있으며, 현재 학위 논문으로 발전시키는 단계에서 실무 적용성을 검증 중입니다."

시스템 시연 영상

약 2분 30초 · 영상을 먼저 시청하신 후 설문에 응답해 주시면 정확도가 크게 향상됩니다

본 영상은 실제 Revit 환경에서 시스템이 5단계 워크플로우(① 매핑 → ② 데이터 추출 → ③ 환산면적 계산 → ④ 최종 결과 → ⑤ 최적화 추천)에 따라 생태면적률을 산출하고 대안을 추천하는 전 과정을 보여드립니다.

  • ✅ Revit 패밀리 → 표준 수종 DB 자동 매핑
  • ✅ 대지 자동 인식 + 그리드 분할
  • ✅ 자연지반 / 인공지반 / 옥상 자동 분류
  • ✅ 가중 그리디 최적화로 부족분 보완 시뮬레이션
  • ✅ PDF 보고서 자동 출력
